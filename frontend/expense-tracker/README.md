## Tech Stack

- **Frontend:** React, Vite, React Router
- **Backend:** Node.js, Express
- **Auth:** JWT, Google OAuth

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm start
```
